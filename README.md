# São Paulo World — showcase page

Static page published at **zrossermcintosh.com/sao-paulo**.

- `sao-paulo/index.html` — the page (no build step)
- `sao-paulo/site_data.json` — snapshot of the tile grid, QA grades, rail lines and street names, generated by `tools/site_build/build_site_data.py` in the SaoPauloWorld project
- `sao-paulo/img/` — city mosaic and renders
- `sao-paulo/driving/` — browser driving test track at **zrossermcintosh.com/sao-paulo/driving**: the OpenRoad Dynamics vehicle core (github.com/ZRosserMcIntosh/Game-Vehicle-Dynamics, MIT) compiled to WebAssembly (`ord.mjs` + `ord.wasm`, rebuilt with `web/build.sh` or `web/build_wasi.sh` in that repo), rendered with three.js (MIT, `driving/vendor/`). Put a Blender export at `driving/models/car.glb` to make it the default car.

Data: © OpenStreetMap contributors (ODbL); GeoSampa, Prefeitura de São Paulo.
- `sao-paulo/glass/` — glass fracture lab at **zrossermcintosh.com/sao-paulo/glass**: the Glass Dynamics fracture core (github.com/ZRosserMcIntosh/Glass, MIT) compiled to WebAssembly (`glass.mjs` + `glass.wasm` + `library.json`, rebuilt with `WASI_SDK=… web/build_wasi.sh sao-paulo/glass` in that repo), rendered with the three.js copy in `driving/vendor/`. Without WebGL it draws a 2D front view (`?flat` forces it). `glass_audio.js` synthesizes the sound from engine events (no audio files); `scene_gt.js` is the armoured-car scenario (`/sao-paulo/glass/?scene=gt` opens straight into it).
